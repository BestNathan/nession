设计问题与验证路径

原型数据均为示例；这些按钮仅模拟 Agent 运行条件，不属于产品界面。

完整交互流程

  1. 在 Timers 列表点击 New Timer，设置 schedule、action、placement。
  2. 选择 macbook-offline 并保存，观察 Server 已保存但 Agent 为 Pending。
  3. 在下方将 macbook 上线；查看任务详情与部署状态变化。
  4. 模拟 Run、查看历史、Pause/Resume、Edit、Delete。
  5. 切换 Web / App，验证弹框与全页表单、返回路径及滚动。

模拟 Agent / 边界

切换目标节点的连接状况，任务的 Definition 不应丢失，也不应自动迁移到其他 Agent。

架构与 UX 边界

Server owns Definition + Placement. Agent owns Binding + execution. Project 是关联者，Session 是资源关联的执行目标；Agent Detail 仅显示分配到该节点的实例。

UI 入口为现有 Workspace 上下文的候选能力，不表示生产中已经有固定全局 Timers 标签。

验证与不足

使用 Nession main 的中性色彩、Typography roles、WorkspaceShell / ResourceDetail / ConfigurationForm / OperationSurface 作为近似。UI 交互为前端内存 mock；未验证真实 Server、systemd、launchd、MCP、生产 Gate/Playwright 或 Pages 发布。
