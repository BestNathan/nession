Self-update nession to the latest version

Usage: nession update [OPTIONS]

Options:
      --check                    Only check for updates (don't install)
      --version <VERSION>        Update/downgrade to a specific version
      --dry-run                  Simulate the update without changing files
      --yes                      Skip confirmation prompt
      --server-url <SERVER_URL>  Server URL (ws:// or wss://). Overrides config and NENSION_SERVER_URL env var [env: NENSION_SERVER_URL=]
      --auth-token <AUTH_TOKEN>  Auth token for server authentication. Overrides config and NENSION_AUTH_TOKEN env var [env: NENSION_AUTH_TOKEN=]
  -h, --help                     Print help
