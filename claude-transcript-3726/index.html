功能验证 · Mock-only

01 · 逐条保留

默认加载最新一页，点击「加载更早记录」查看完整样本。包含 user、assistant、thinking、tool use、tool result、system、attachment、metadata、未知类型、损坏 JSON 与大记录。

02 · 双层查看

点击行展开语义详情；点击行右侧 Raw 打开独立检查器，可切换 JSON 树 / 原始文本并复制。未知、损坏和大记录入口一致。

03 · Web / App

Web 采用 Claude 能力内列表与时间线；App 为列表 → 时间线 → Raw 的推入层级，使用单一 Back。无全局新功能入口或解析状态徽章。

04 · 增量与归属

外部模拟按钮可追加未来未知类型或切换当前 Session。验证新记录不清空已读历史、切换上下文会撤销 Raw 与旧选择。
