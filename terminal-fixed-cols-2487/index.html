验证说明与边界

本页面用真实 DOM/CSS 字体渲染和实际字形测量替代“按 0.6 比例推测”，没有把手机终端截图放大。样本文本限定为单宽 ASCII，按共同列数精确拆行并对齐。行高是浏览器 CSS line-height 模拟，不是 xterm 的渲染器实测行高；最终生产实现应使用 xterm 测量、ControlLease、有序输出与真实 tmux 进行验证。若字体网络加载失败将使用系统等宽回退字体，并重新测量。
