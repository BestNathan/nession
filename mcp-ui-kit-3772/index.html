Functional contract and fidelity

Runtime boundary

UI Kit renders data/actions from caller-supplied Adapter; only the selected host/Session Agent may mutate config or invoke a Tool. #3251 owns non-project resources, #3600 owns Claude local/project effective config, nession-mcp owns server contracts. No auto probe on view.

Schema / result contract

Input Schema and Output Schema are independent contracts. Structured result, content blocks, isError and full raw envelope remain separate. Missing external outputSchema stays “not advertised”; unknown fields remain in Raw.

Security & effects

All endpoints are synthetic, credentials are references only. The mock never starts subprocesses, sends network requests, invokes MCP or changes files. Real invocation requires permissions, risk confirmation and bounded execution by the Adapter.

Verification boundaries

Source-aligned candidate using baseline CSS and shared prototype frame. Chromium click-through/pixel comparison, real credential/protocol tests, Pages immutable SHA/manifest HTTPS readback and production Acceptance are not proven by this mock.
