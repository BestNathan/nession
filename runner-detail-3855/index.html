完整路径

  1. Overview 阅读指标、采样时间、覆盖范围。
  2. Jobs → 选择历史 Job → 选择 Step → Logs。
  3. 在日志页搜索、复制、返回；Web/App 宽度互切。
  4. 检查空闲、离线、指标缺失和 API 错误。

功能边界

CPU、RSS、I/O 和目录大小只统计可验证的 Runner 进程/目录，不归因到某个 Job。GitHub 只提供有界任务发现，不能声称全量 Job 历史。日志按需读取，不承诺流式。

忠实度与验证

参考当前 Session-first Workspace、Agent Detail 以及 Nession 中性色和排版；App 只有 WorkspacePanel 的一个 Header/Back。静态模拟，未连 API/系统服务，实际浏览器、Pages SHA 和生产 E2E 尚未验证。
