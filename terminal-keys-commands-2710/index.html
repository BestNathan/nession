功能设计与交互说明

下方是评审资料，不属于 Nession App。可直接在上方真实尺寸预览里操作。

核心能力

  1. Terminal Keys：直接发送 Esc、Tab、Enter、方向键和快捷组合键。
  2. Ctrl / Alt / Shift 是一次性修饰键；选择字母后发送一个组合事件并清除状态。
  3. Quick Commands：区分 Insert（插入文本）和 Run（提交并执行）。
  4. Capsule 的展开只增加可逆滚动空间，不自动推走已有终端内容。

手动验收路径

  1. 点击 + → Terminal Keys → Ctrl+C；观察下方事件日志。
  2. 选择 Ctrl → X；再次进入并 Cancel。
  3. 切换 Commands，分别尝试 Insert 与 Run。
  4. 保持 Keys / Commands 展开，在 Terminal 上滚动至最新输出，再恢复到最初行。
  5. 用 375 / 390 / 430 宽度重试，不改变终端行数。

视觉基线与已知差异

产品结构参考主干 SessionHeader、TerminalSurface、TerminalCapsule、capsuleStyles 及 FixtureTerminal。本预览使用固定版本 --nession-* Token 快照，保留 App Capsule 的可触控尺寸和浮层关系。

尚未达到像素级还原：这里的 Terminal 仍是 DOM 文本，不是 xterm.js；部分 Header、Keycap 和真实 TUI 布局只做近似。屏幕的 1:1 尺寸不代表真实组件已经逐像素一致。

模拟范围与验证证据

使用模拟命令清单与事件，未连接 Server / Agent、PTY、tmux，也不会执行实际 shell 命令。滚动清障使用 DOM padding，不能代替生产 xterm 的证明。
