Functional design & verification

This prototype exercises presentation and return semantics; it does not create Sessions, probe real addresses, configure a remote Agent, or connect to a Terminal.

Attach — two intents

  1. Web: Session → Attach; compare Auto/P2P/Relay, inspect complete candidate address, re-test, confirm.
  2. App: Sessions → Attach opens a compact sheet; Connection settings pushes a full view; Back restores the sheet and its draft; Attach is explicit.
  3. Session → Attach settings enters the full configuration directly on App. Save changes preference only; it must never attach.

Project → new Session

  1. Web: Project detail → New Session opens a 640px dialog. Location trigger shows Agent + directory + status; opening its anchored overlay shows Agent + path only and does not push Session Name. Search Env files, review source badges and var counts, and select multiple rows with 16px indicators.
  2. App: Project detail → New Session pushes one full-height operation page. Location and ENV each open child selectors. Back preserves the draft.
  3. Try “Very long path / address” with the selector both closed and open at Web 1440, 1180 and 1024. The same menu remains usable on narrow forced Web; offline blocks submission without erasing the draft. Cancel preserves the previous Terminal.

New Project — field alignment (#3136)

Open New Project from the Web Sidebar: Name, Description, Git URL/ref, optional Existing Locations and Image reference appear in the same consistent form grid. Add a Location and compare the Agent select, Directory textarea and Remove control: labels and field tops align on the Experience control band (32px Web / 44px App), a long Directory grows downward without moving Agent or Remove, and Remove sits in the label slot. New Project starts without locations; Settings uses existing locations. App stacks each full-width row.

Fidelity & boundary

Presentation is a candidate based on the current WebLayout, AppLayers, AttachDialog, CreateSessionDialog and ProjectDialogs ownership. Product palette is a localized token snapshot. The Web location selector is a deterministic mock of the intended content-height Select. The Project form follows the staging field inventory and flow, not an authenticated implementation. Production React layout parity and acceptance still require their own Chromium Cases.
