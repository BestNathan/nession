场景控制仅用于外部评审，不属于实际 App UI。建议先完整走一遍 Browse → Detail → Back 路径。

01 · Conversation is work

默认进入当前绑定对话。消息、工具活动与会话标题占据主体；没有伪造的 Claude 回复输入框。

02 · One resource entry

Browse 中统一入口：Conversations、Transcripts、Memory、MCP、Configuration。资源内部推进详情，不把全部功能压入顶部 Tab。

03 · Honest states

切换 No binding / Agent offline / Verified working 验证对话归属、安全状态展示与来源切换。

04 · App depth

Transcript 逐条可见且可查看 Raw，MCP 工具展示 schema，配置文件单列推进。返回不替代 Terminal 的工作现场。
