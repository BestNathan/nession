测试场景 · 不属于产品 UI

UI 设计标注与交互验收

下方为评审辅助区域，独立于 App 可见屏幕。所有数值来自固定的 Nession App Token 快照或明确标注为本原型候选，并支持读取预览中的实际 DOM 几何数据。

核心路径

  1. 从 Sessions 列表选一个未选中的 Session 行尾 ···，打开四项菜单。菜单不会自动切换工作。
  2. 选择 Session details 查看 tmux 名、位置、状态、描述、Tags。关闭仍在 Sessions。
  3. 选择 Edit details 修改 Title、Description、Tags；保存后行标题更新，但删除仍需要旧 tmux 名。
  4. 测试 Attach settings 和 Kill session；杀掉 Session 之前必须准确输入 tmux 名。
  5. 测试离线 Agent、模拟并发冲突、搜索/筛选、关闭菜单和返回 Terminal / Workspace；从 Sessions 向左滑动可以返回原 Terminal。

体验边界

App 保留 Sessions ← Terminal → Workspace。Sessions 是独立空间层，而不是折叠的 Web Sidebar；点击会话行才切换正在工作的 Session，点击菜单仅操作目标。

Session metadata 沿用既有 title/description/tags 领域语义；会话标识、tmux 名和 Agent 不可在编辑表单中修改。销毁前的名称确认不可省略。

规格量测 · 预览中实时读取

选择组件，读取尺寸、字号、圆角、CSS Token 和实际可见状态。

产品 Token：--nession-typography-title-size=17px、--nession-typography-primary-size=16px、--nession-typography-body-size=14px、--nession-shell-icon-button-size=44px。列表控件触控目标至少 44px。

数据与验证声明

本原型使用纯静态 HTML/CSS/JS + 公开安全的虚构数据。按钮只修改浏览器内存；配置不会连接 Agent，删除不会杀真实进程，Terminal 是文字示意而非 xterm，不能证明 PTY/重连或真实滑动手势。
