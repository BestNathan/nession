# Nession instruction ownership model

Nession uses a layered instruction architecture: root `AGENTS.md` for repository-wide constraints, nearest scoped `AGENTS.md` for path-local invariants, `.claude/skills/*/SKILL.md` for repeatable task workflows, and canonical docs/code/Gates for detailed and executable truth. The `.agents/skills` path is a symlink to the single physical `.claude/skills` tree rather than an independent copy.

This entry summarizes **repository instruction discovery** only. It does not override current files or guarantee that a given external agent has loaded a Skill.
