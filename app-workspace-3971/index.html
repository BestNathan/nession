以下为评审说明，不属于 App 产品界面。所有资源、操作与数据都是本地模拟。

Token reference: App 17 / 16 / 14 / 13 / 12 / 11.5 px typography roles; 44px touch targets; canonical Nession neutral surfaces, borders and semantic radii. Light / Dark changes the product tokens only; the review frame remains independent.

01 · Stack Header

主标题表示当前资源，副标题表示真实父路径。点击副标题打开祖先栈；右侧使用高频图标和 More，没有第二条导航栏。

02 · Semantic surfaces

Claude 使用连续 Reader，Git 使用分组 Collection，Sandbox 使用 Configuration 分区，Files 的编辑器是独立工作表面。保留公共 Canvas 与 Capsule。

03 · Icon-first actions

Header / Row 仅显示必要图标，实际菜单与危险操作使用可读文本；44px 触控区域、焦点态和 accessible label 一致。

04 · Stack Swipe

右滑 Pop，左滑仅在真实 Forward History 存在时前进；取消手势回弹。编辑器及弹层保护自身交互，未保存改动需要确认。
